Event ticketing on Sepolia

Simple Web3 DApp: create a wallet, check Sepolia ETH and ticket (ERC-20) balances for attendees, doormen, and venue staff, purchase tickets with native test ETH, and transfer tickets back to the vendor.

Go to a page

Create wallet Generate keys, view address, download keystore JSON. Check balance Crypto (ETH) and ticket token balance for any address. Buy ticket Load wallet and send a payable transaction to the contract. Transfer to vendor Return ticket tokens to the vendor wallet.
